# Ұшқан ұя

Фронтенд платформы по повести Бауыржана Момышұлы для 9-го класса.

## Что уже подготовлено

- Проверка академической добросовестности до отправки работы.
- Отслеживание шести уроков, теста, трёх игр и готовности итогового анализа.
- Оценивание по критериям A и D с персональной обратной связью; диаграмма ученика
  открывается после завершения учебного пути и оценивания.
- Разделы `#results` для личной и административной визуализации результатов.

## Подключение API

Бэкенд расположен отдельно в репозитории `project-mom-back`. Его Railway-адрес
зафиксирован в `dist/auth.js` как `API_BASE`. На бэкенде `FRONTEND_ORIGIN` должен
совпадать с публичным адресом этого фронтенда.

## Роли и маршруты

| Кто | Действие |
| --- | --- |
| Ученик | Учебные разделы, итоговая работа и `#results` |
| Администратор | Вход, проверка работ, результаты и исследовательская выгрузка — после подключения API |

## Локальная проверка

```bash
node scripts/verify-static.cjs
```

Для сохранения работ и результатов нужен отдельно развернутый API.
