# Ұшқан ұя

Учебная платформа по повести Бауыржана Момышұлы для 9-го класса.
Готовые HTML, CSS, JavaScript и учебные материалы находятся в `dist/`.

## Развёртывание на Vercel

Импортируйте этот репозиторий и ветку `main` в Vercel.
Root Directory — корень репозитория, Framework Preset — Other.
Сборка и установка зависимостей не требуются; Output Directory — `dist`.
Эти настройки уже указаны в `vercel.json`.

Разделы используют адреса вида `/#theory`; дополнительные правила маршрутизации не нужны.
Ключи API и серверные сервисы для работы платформы не требуются.

## Данные учеников

Ответы хранятся в памяти открытой страницы. Перед закрытием или обновлением
ученик должен скачать свою работу. Автоматической отправки учителю нет.

## Локальный просмотр

Запустите любой статический HTTP-сервер с папкой `dist` в качестве корня.

Настройки хостинга: https://vercel.com/docs/project-configuration/vercel-json
