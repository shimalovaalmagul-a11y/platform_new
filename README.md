# Ұшқан ұя

Платформа по повести Бауыржана Момышұлы для 9-го класса. Ученики регистрируются,
отправляют анализ и при необходимости прикрепляют PDF, DOCX или TXT до 4 МБ.
Администратор видит все работы и скачивает приложения в панели `#admin`.

## Что уже подготовлено

- Vercel API: регистрация, вход, выход, текущая сессия, отправка работ и админ-панель.
- MongoDB: пользователи, работы и GridFS для файлов.
- Роли: `student` для учеников, `admin` для администратора.
- Сессия в защищённой HTTP-only cookie на 7 дней.
- Проверка академической добросовестности до отправки работы.

## Подключение MongoDB и Vercel

1. Импортируйте репозиторий и ветку `main` в Vercel. Root Directory — корень репозитория,
   Framework Preset — Other. Конфигурация `vercel.json` сама укажет `dist` как каталог сайта.
2. В Vercel → Project Settings → Environment Variables добавьте значения из `.env.example`:
   `MONGODB_URI`, `APP_JWT_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` и при необходимости
   `MAX_UPLOAD_BYTES`.
3. В MongoDB Atlas создайте базу; в строке подключения укажите имя базы `ushqan_uya`.
   Разрешите подключение от Vercel в настройках Network Access Atlas.
4. После этого можно запустить первый deploy из Vercel. При первом входе API создаст
   администратора из `ADMIN_EMAIL` и `ADMIN_PASSWORD`.

Если потребуется сменить пароль администратора, измените `ADMIN_PASSWORD` в Vercel и
сделайте redeploy: API обновит его хэш при следующем обращении.

Не добавляйте настоящие пароли и строку MongoDB в Git. Файл `.env.example` — только шаблон.

## Роли и маршруты

| Кто | Действие |
| --- | --- |
| Ученик | `#account` → регистрация/вход → `#submit` → отправка анализа и файла |
| Администратор | `#account` → вход → `#admin` → просмотр текстов и скачивание файлов |

## Локальная проверка

```bash
npm install
npm run check
npm test
npm run build
```

Для полноценной локальной проверки API требуется `.env` с параметрами из `.env.example` и MongoDB.
